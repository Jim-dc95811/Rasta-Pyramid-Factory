# Rasta Pyramid Factory v0.1.3 TEST

**Status: LIVE-PROVEN — 2026-08-16**

v0.1.3 is the first build after Rasta's automated pipeline became LIVE-PROVEN on the 29,684 × 7,620 Montreal skyline source.

## New in this build

### Synthetic parking off Florida

Ordinary flat images no longer appear at longitude/latitude 0,0 off Africa. Rasta now uses a fixed synthetic display anchor at **30°N, 80°W**, east of Florida. The placement remains explicitly synthetic and does not change image detail.

### Visible life during long jobs

The normal GUI now maintains a continuously changing status line with:

- changing heartbeat glyph;
- elapsed time;
- current manufacturing stage;
- last meaningful worker message;
- real numeric QGIS progress when available.

This addresses the live v0.1.2 observation that a healthy long QGIS operation could look frozen to an ordinary user.

## Preserved behavior

- automatic flat/georaster decision;
- optimized tiled GeoTIFF staging for giant flat inputs;
- working overview generation;
- headless QGIS 3.44.9 rendering;
- MBTiles / TPKX / Both outputs;
- frozen MBTiles→TPKX converter;
- verification, cleanup, cancellation, and single-instance protection.

## Remaining hardening

The v0.1.3 architecture is live-proven, but release hardening still includes cancellation testing, MBTiles-only/Both output testing, a genuine georaster AUTO-mode test, and broader very-large-raster coverage.

## Live acceptance update — 2026-08-16

v0.1.3 was subsequently observed live on Windows using an 8,003 × 5,622 Frankfurt city JPEG. Automatic flat-image detection, Atlantic synthetic parking near 30°N/80°W, verified TPKX publication, and ArcGIS Earth display all passed. See `docs/ACCEPTANCE_RECORD.md`.
