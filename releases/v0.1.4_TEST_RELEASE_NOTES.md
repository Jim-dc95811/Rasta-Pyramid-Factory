# Rasta Pyramid Factory v0.1.4 TEST

**Status: BUILT / SELF-TESTED**

v0.1.4 keeps the v0.1.3 LIVE-PROVEN raster/QGIS/TPKX baseline and changes the finished-product selector.

## Output selection

Three independent choices:

- TPKX
- MBTiles
- REST

Any one, any two, or all three may be selected.

## Manufacturing behavior

QGIS renders one verified temporary MBTiles pyramid. The Factory then publishes only the selected products:

```text
one QGIS MBTiles render
    ├── TPKX
    ├── MBTiles
    └── REST
```

The REST branch converts the verified MBTiles into the WMTS-compatible tile folder explored for Map Fountain. It does not rerender the raster tiles.

## Acceptance boundary

The v0.1.4 selection logic and REST branch are self-tested. The package is not labeled LIVE-PROVEN until a real end-to-end run succeeds on the Windows Factory target and the applicable downstream target accepts the selected output.

The current personal-phone deployment direction has since moved toward direct local TPKX on microSD, so REST-specific work is not the current priority.

**v0.1.3 remains the LIVE-PROVEN Rasta baseline.**
